Updating

Download again, extract over the same folder, then click Reload on the extension card.

Graphics startup fails in a Linux VM

If the extension reports “Startup failed during graphics initialization” in Brave, try these steps:

  1. Open brave://settings/system and enable Use graphics acceleration when available. Your VM’s 3D acceleration can remain disabled.
  2. Fully quit Brave, then launch it from a terminal:
    brave-browser --disable-gpu-compositing --ignore-gpu-blocklist
  3. Reopen the extension.

This configuration worked with VM 3D acceleration disabled, including on Whonix. If startup still fails, open brave://gpu, select Download Report to File, and include the report in your bug report.
